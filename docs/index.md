# PortSwigger Web Security Academy — Lab Write-Ups

Welcome! This site documents how I worked through
[PortSwigger's Web Security Academy](https://portswigger.net/web-security)
labs, organized by vulnerability category.

👉 **To see how I approached a specific category, click one of the links
below.** Each one takes you to that category's own write-up site, covering
the labs, my methodology, and the root cause of the vulnerability.

## 📂 Browse by category

- [**SQL Injection**](sql-injection/) — how I exploited flaws in database queries to read, modify, or bypass application logic.
- [**File Upload Vulnerabilities**](file-upload-vulnerabilities/) — how I abused weak upload validation to plant malicious files on a server.
- [**Race Conditions**](race-conditions/) — how I exploited timing windows where concurrent requests broke app assumptions.
- [**Path Traversal**](path-traversal/) — how I escaped intended directories to read or write arbitrary files.
- [**CORS**](cors/) — how I exploited misconfigured cross-origin policies to leak data across origins.
- [**Web LLM Attacks**](web-llm-attacks/) — how I used prompt injection and other attacks against LLM-integrated applications.
- [**API Testing**](api-testing/) — how I found and exploited flaws specific to API design and implementation.
- [**Server-side Vulnerabilities**](server-side-vulnerabilities/) — how I exploited SSRF, deserialization, and other server-side logic flaws.

## About

I'm working through these labs to build hands-on offensive security skills.
Each write-up documents the vulnerability, how I exploited it, why it works,
and how it should be fixed — from an educational, defensive-minded perspective.

📌 All content here is based on my own testing against PortSwigger's
intentionally vulnerable training labs, for educational purposes only.
